# Екатерина Казанская
### Аналитик данных | Аналитика логистики и операционных процессов

Более 15 лет опыта в международной морской и контейнерной логистике. Прошла профессиональную переподготовку по направлению «Аналитик данных» в Томском государственном университете. Использую SQL и Python для анализа данных, а Yandex DataLens и Power BI — для визуализации результатов.

В портфолио — проекты по анализу выручки с помощью SQL, исследованию клиентских данных на Python и созданию интерактивного дашборда в Yandex DataLens.

### 🛠 Инструменты

- **SQL:** SQLite, PostgreSQL
- **Python:** pandas, NumPy
- **Визуализация:** Yandex DataLens, Power BI
- **Анализ данных:** EDA, предобработка, описательная статистика, проверка гипотез
- **Среда разработки:** Jupyter Notebook, DBeaver

### 📊 Проекты

**1. [Анализ выручки тарифов — SQL](https://github.com/katrinasbor15/telecom-tariff-revenue-analysis)**

Расчёт выручки тарифов Smart и Ultra, агрегация данных по пользователям и месяцам, сравнение общей и средней выручки.

**2. [Дашборд клиентской базы банка — Yandex DataLens](https://github.com/katrinasbor15/bank-customer-dashboard-datalens)**

Интерактивный дашборд с показателями платёжной дисциплины, анализом переводов, распределением клиентов и фильтрами по регионам и операторам.

**3. [Итоговый проект — портреты заёмщиков банка](https://github.com/katrinasbor15/Final-learning-project)**

Исследовательский анализ данных клиентов банка, предобработка данных, анализ факторов, связанных с платёжной дисциплиной, и формирование портретов клиентов.
